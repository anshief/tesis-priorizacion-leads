# Reading guide

1. Read the [anonymized public thesis (Spanish)](../../tesis/tesis_publica_anonimizada.pdf) for context, methodology, aggregate results, and limitations.
2. Review the [consolidated notebook](../../04%20Notebook%20Final/notebook_final_presentacion.ipynb) to follow the technical structure. It contains no stored outputs or original models.
3. Run the [synthetic demonstration](REPRODUCIBILITY.md) to try the integration contract.

Research code is organized by stage: preparation, K-Means, prediction, final notebook, and integration. The public edition generalizes names and removes business-specific configuration; the feature engineering script explicitly identifies that adaptation.

Historical metrics are available in the adapted academic document. Demonstration outputs refer exclusively to invented records.

The code, notebook commentary, academic PDF, and original folder names remain in Spanish. This guide and the [case study](CASE_STUDY.md) provide an English reading path without renaming files or changing program behavior.
