# Guía de lectura

1. Lee la [tesis pública anonimizada](../tesis/tesis_publica_anonimizada.pdf): contexto, metodología, resultados agregados y límites.
2. Revisa el [notebook consolidado](../04%20Notebook%20Final/notebook_final_presentacion.ipynb) para seguir la estructura técnica. No contiene salidas ni modelos reales.
3. Ejecuta la [demostración sintética](REPRODUCIBILIDAD.md) para probar el contrato de integración.

El código de investigación se organiza por etapas: limpieza, K-Means, predicción, notebook final e integración. La edición pública modifica nombres y retira configuración comercial; el script de ingeniería de variables identifica expresamente esa adaptación.

Las métricas históricas se consultan en el documento académico adaptado. Las salidas de la demostración corresponden exclusivamente a datos inventados.
